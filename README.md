# 分享链接清理

从抖音、小红书、淘宝、B 站、知乎、微博、拼多多、京东等 App 的分享文案里，提取真实链接并打开。

很多分享内容会带上一大段说明文字，例如：

```
7.92 复制打开抖音，看看【xxx的作品】https://v.douyin.com/abcXYZ/ Z@m.Fd 02/18
【淘宝】https://m.tb.cn/h.xxx?tk=yyy CZ0001 「商品名」点击链接直接打开
```

也支持整段或链接被百分号编码（例如 `https%3A%2F%2Fv.douyin.com%2Fabc%2F`）的情况。

Chrome 不允许扩展直接改写地址栏里正在粘贴的内容，所以本扩展提供两种接近的用法。

## 安装

1. 下载并解压 `share-link-cleaner.zip`（或直接使用本文件夹）。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的 `share-link-cleaner` 文件夹（文件夹里应能看到 `manifest.json`）。

如果之前已经加载过旧版本，请在扩展卡片上点击 **重新加载**，不必删除后重装。本次请确认版本号为 1.1.1。

## 用法

### 1. 快捷键（默认 Alt+V）

复制 App 分享文案后，按 `Alt+V`（Mac 上是 Option+V）。扩展会读取剪贴板、提取其中第一条有效链接，并在你原来正在看的那个标签页打开（包括新标签页 `chrome://newtab`）。如果当时必须弹出一个小窗口来读取剪贴板，提取成功后也会跳转回原来的标签页并关闭小窗口。

快捷键可在 `chrome://extensions/shortcuts` 中自行修改。

提示含义：

- 橙色 `?`：没能读到剪贴板（常见于新标签页、设置页等受限页面）。扩展会尝试打开弹窗，把分享文案粘贴进去即可。
- 红色 `!`：已经读到剪贴板内容，但其中没有可用的 http(s) 链接。

### 2. 地址栏关键字 `u`

1. 在地址栏输入 `u`，再按空格（或 Tab）。
2. 粘贴整段分享文案。
3. 输入过程中会预览提取到的链接，按回车即可打开。
   - 直接回车：在当前标签页打开
   - Alt+回车：在新标签页打开（前台）
   - 按住 Ctrl/Command 点选建议：在后台标签页打开（取决于浏览器的 disposition 行为）

### 3. 弹出窗口

点击工具栏图标，扩展会尝试读取剪贴板并显示提取结果。可以点 **打开链接**，或把文案粘贴到输入框里再提取。

## 说明与限制

- 无法做到「把文案直接粘贴进地址栏就自动变干净」，这是 Chrome 对地址栏的限制，不是本扩展能绕过的。
- 只提取 `http` / `https` 链接；像 `snssdk://`、`taobao://` 这类 App 协议不会处理。
- 若文案里有多个链接，会使用第一次出现的那条。查询参数（例如淘宝的 `tk=`，以及其中已有的百分号编码）会保留。
- 没有 `https://` 前缀、但带路径的短链（如 `v.douyin.com/xxx`、`b23.tv/xxx`）会自动补上 `https://`。
- 被百分号编码（甚至双重编码）的文案会先解码再识别；如果原文里已经有完整的 `http(s)://` 链接，则按原文提取，以免把查询参数里的编码解开。
- 在新标签页、`chrome://` 设置页、Chrome 应用商店等页面，扩展无法向页面注入脚本读取剪贴板。这时会改用备用方式，或打开弹窗让你粘贴。
- 首次使用时，个别系统可能会询问剪贴板权限，需要允许。
- 默认快捷键 `Alt+V` 若与其他扩展冲突，请到 `chrome://extensions/shortcuts` 更换。

## 开发

提取逻辑在 `extract.js`，可用 Node 运行测试：

```bash
node --check extract.js service-worker.js offscreen.js popup.js test/extract.test.js
node test/extract.test.js
```

调试快捷键时，可在 `chrome://extensions` 打开本扩展的 **服务工作进程 / Service worker**，控制台里会输出以 `[分享链接清理]` 开头的日志。
